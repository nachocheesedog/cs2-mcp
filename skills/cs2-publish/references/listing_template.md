If the author uses a credit line (e.g. a note on the tools used), keep its wording identical in every listing, at
the end, written without asterisks.

Plain text only, no markdown: no '- ' bullets, no ** bold. In chat, give EVERY field in its own copy-pasteable code box.
Format it properly: UPPERCASE section headers, '•' bullet characters, a blank line between sections. Also write the
long description alone to <Name>_description.txt and send it to the user as a file: chat markdown collapses single
line breaks, so the file is the copy source.

Checks: count characters (name ≤ 60, short ≤ 200). No real person's name other than the architect or
historical figures. No local paths. Facts must come from the project memory or research notes, never be invented.
If a gameplay number isn't verified in game, mark it [confirm in game] and ask.
